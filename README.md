# Pizza Hut Mongolia бүтээгдэхүүний лавлах

Илгээсэн таван лавлах зурагт тусдаа бүтээгдэхүүнээр нэрлэсэн 56 бүртгэл. Экспресс салбарын зүсэм, порц болон хэмжээний сонголтыг холбогдох бүтээгдэхүүнд хавсаргасан. Жагсаалтад давтагдсан бүтээгдэхүүнийг нэг удаа оруулсан.

| Ангилал | Бүртгэл |
| --- | ---: |
| Багц | 9 |
| Пицца | 18 |
| Нэмэлт ба амттан | 20 |
| Ундаа | 9 |

## Ашиглах

- [Онлайн каталог](https://bayartsogtb89-eng.github.io/pizzahut-mongolia-menu/) дээр нэр, тайлбараар хайж, ангиллаар шүүнэ.
- Офлайнаар ашиглах бол ZIP-ээ задлаад `index.html`-ийг нээнэ. `data/menu.csv`-г Excel-д нээж болно.
- `data/menu.json` нь засварлах үндсэн файл. Засвар хийсний дараа `python3 scripts/rebuild.py` ажиллуулж HTML болон CSV-г шинэчилнэ.

## Эх сурвалж

- Үнэ, сонголтыг лавлах зурагт бичсэнээр оруулсан. Зурагт үнэ дурдаагүй хоёр соусанд өмнөх цахим цэсний үнийг хадгалсан.
- «Гарахгүй байгаа» гэсэн тэмдэглэгээ дөрвөн бүтээгдэхүүнд хадгалагдсан. Тэмдэглэгээ, үнийг тухайн өдрийн нөөц, үнээр баталгаажуулаагүй.
- Өмнөх каталогийн тохирох 47 зургийг ашигласан. Үлдсэн 9 бүртгэлд тохирох зураг баталгаажаагүй. Бүтээгдэхүүний зураг болон брэндийн эрх холбогдох эрх эзэмшигчид хамаарна.
