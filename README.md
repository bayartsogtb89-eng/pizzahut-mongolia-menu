# Pizza Hut Mongolia бүтээгдэхүүний лавлах

2026 оны 11 сарын 26-нд Улаанбаатарын цагаар албан ёсны захиалгын сайтад салбар сонгохоос өмнө харагдсан цэсний хуулбар. Нийт 75 бүртгэлтэй.

## Ашиглах

- ZIP-ээ задлаад `index.html`-ийг хөтөч дээр нээнэ. Нэр, тайлбараар хайж, ангиллаар шүүнэ. Зургууд `images/` дотор байгаа тул интернетгүй үед ч харагдана.
- `data/menu.csv`-г Excel-д нээж болно. `data/menu.json` нь засварлах үндсэн файл.
- Өгөгдлөө зассаны дараа `python3 scripts/rebuild.py` ажиллуулж HTML болон CSV-г шинэчилнэ.
- GitHub дээр байршуулах бол энэ хавтасны файлуудыг шинэ репод оруулна.

## Хамрах хүрээ

- Үнэ нь анх харагдсан үнэ. Пиццаны хувьд анхны хэмжээ ба гурил, мөн цэсэнд харагдсан хэмжээ, тухайн эхний хэмжээний гурилын сонголтыг тэмдэглэсэн. Бусад хувилбарын үнэ, багцын бүх тохируулга болон салбар тус бүрийн нөөц тусгагдаагүй.
- Сайтад «Пепперони» нэрээр хоёр тусдаа зурагтай бүртгэл байсан тул хоёуланг хадгалсан.
- Зарим тайлбар сайт дээр тасарсан байсан. Тэдгээрийг `description_partial` талбараар тэмдэглэсэн. Цэсний тайлбар нь харшил үүсгэгчийн бүрэн жагсаалт болохгүй.
- Зургийн эх URL болон цэсний эх сурвалж бүтээгдэхүүн бүрийн өгөгдөлд бий. Бүтээгдэхүүний зураг, брэндийн эрх холбогдох эрх эзэмшигчид хамаарна.
